VETRA 4.2.1 — CROSS-DEVICE PUBLISHING

1. Extract this ZIP into the repository root and replace the old files.
2. Run supabase/content.sql in the Supabase SQL Editor.
3. Add the Vercel environment variables listed in CROSS-DEVICE-SETUP.md.
4. Keep Vercel Root Directory blank.
5. Commit, push and redeploy after adding the environment variables.
6. Open /0 and sign in.
7. Click Connect publishing and enter the same CONTENT_ADMIN_KEY configured in Vercel.
8. Click Publish now and wait for the green Published badge.

After connection, every admin Save publishes automatically to all devices.

VERIFY
- Admin header says Admin · v4.2.1.
- The cloud badge says Published.
- document.body.dataset.vetraVersion returns 4.2.1.
- Open the storefront in an incognito window or on a phone; it should load the same content.

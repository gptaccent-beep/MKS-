VETRA 2.1.0 DEPLOYMENT

IMPORTANT: The ZIP contents must be the ROOT of the Vercel project.
You should see index.html, vercel.json, package.json, README.md and assets/ immediately after extracting — not another folder.

REPLACE THE OLD DEPLOYMENT
1. Delete the old project files from your GitHub repository (keep the .git folder).
2. Copy every extracted file and the assets folder into the repository root.
3. Commit and push.
4. In Vercel, open Deployments → Redeploy the latest commit → disable “Use existing Build Cache”.
5. Open the new deployment in an Incognito window.

CONFIRM VERSION 2.1
- The header must show an EN / FR / AR selector.
- /0 must show Catalog, Media, Homepage, Orders, Themes and Settings.
- Browser DevTools → Network → the page response includes X-VETRA-Version: 2.1.0.

If these are not visible, Vercel is still deploying the old repository/branch or the wrong Root Directory. Set Project Settings → Build & Deployment → Root Directory to the folder containing index.html (normally blank / repository root).

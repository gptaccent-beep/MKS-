VETRA 3.0.0 DEPLOYMENT

1. Extract this archive. index.html, vercel.json, api/, i18n/, supabase/ and assets/ must be at the repository root.
2. Replace the old repository files instead of merging only index.html.
3. Commit and push.
4. In Vercel, redeploy without the existing build cache.
5. Confirm the EN / FR / AR selector and the new Analytics item at /0.

OPTIONAL SHARED ANALYTICS
- Run supabase/analytics.sql.
- Add SUPABASE_URL, SUPABASE_SERVICE_ROLE_KEY and ANALYTICS_ADMIN_KEY from .env.example to Vercel.
- Redeploy.
- In Admin → Analytics, choose Sync cloud and enter ANALYTICS_ADMIN_KEY.

Without those variables, timestamped raw analytics still work locally in the current browser for preview/testing.
